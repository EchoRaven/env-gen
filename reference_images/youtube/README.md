# YouTube reference screenshots

Drop screenshots of the real YouTube here — the visual-fidelity gate scores the
generated screens against these. PNG or JPG. Suggested set (4–6 is plenty):

| filename | page to capture |
|----------|-----------------|
| `home.png` | Home — the video grid + left sidebar + top search bar |
| `watch.png` | A video watch page — player + title + channel + like/subscribe + comments + "up next" |
| `channel.png` | A channel page — banner, avatar, subscriber count, video grid |
| `search.png` | Search results for some query (the vertical list of videos) |
| `subscriptions.png` | The Subscriptions feed |
| `library.png` | Library / History / playlists |

Filenames are a hint, not a hard requirement — the pipeline reads every image in
this folder and maps them to screens. Once they're here, launch with
`./run_youtube.sh` (Gemini).
