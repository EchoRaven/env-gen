# Netflix clone

Multi-profile streaming catalog built from `design/` (dataset, posters, backdrops, clips, logo, icons, fonts).

```
cd docker && docker compose up --build
```

- Frontend (React + Vite build served by nginx; proxies `/api`, `/auth`, `/health`): http://localhost:3000
- Backend (FastAPI): http://localhost:8000 (`GET /health`)
- Database: Postgres 16. `app/database/init/` holds the schema and the seed. The seed is generated by `tools/gen_seed.py` from `design/dataset/titles.json`.
- Demo account: `demo@netflix.local` / `netflix123` (profiles Demo, Alex and Kids)

## API notes
- `POST /auth/register` and `POST /auth/login` return `{access_token, token_type, user}`. Every `/api/*` route requires `Authorization: Bearer <token>`.
- Per-profile data (My List, ratings, Continue Watching) uses the profile from the `X-Profile-Id` header, or from `?profile_id=` or a `profile_id` field in the body. Without one, the account's first profile is used. Another account's profile returns 403.
- `DELETE /api/my-list/{id}` takes a list-entry id; `?by=title` makes it a title id.
- Ratings: `-1` thumbs down, `1` thumbs up, `2` love, `0` clears the rating.
- Extra routes used by the UI: `GET /api/me`, `PATCH/DELETE /api/profiles/{id}`, `GET /api/ratings`, `GET /api/my-list/{id}`, `GET /api/titles/{id}/rating`, `POST /api/continue-watching` (player progress), `GET /api/genres/{id}`.
- Kids profiles only see titles in the Family and Animation genres. Every title in the dataset is rated TV-14, so maturity rating can't be used for this.
