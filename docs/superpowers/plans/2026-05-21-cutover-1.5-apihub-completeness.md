# Cutover 1.5 — APIHub Completeness

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development or superpowers:executing-plans. Steps use `- [ ]`.

**Goal:** Round out APIHub's public API so the LLM tool layer no longer reaches into private CRDT stores. Add 5 public methods + 1 review-submission flow, then refactor 4 existing tool classes to use them.

**Why now:** Audit (`docs/superpowers/audit-reports/2026-05-21-crdt-strip-audit.md`) flagged this as the only non-cosmetic gap in APIHub. Doing it as a small dedicated PR keeps the surface clean before Cutover 2 (EventHub bridge) starts adding cross-hub event handlers.

**Out of scope:** Table migration (defer to Cutover 3 decision), schema diff utility, OpenAPI export, mock server runtime.

**Source spec:** `docs/superpowers/specs/2026-05-21-four-hubs-design.md` §5 (APIHub).
**Audit:** `docs/superpowers/audit-reports/2026-05-21-crdt-strip-audit.md` §2.2.

```python
    def submit_api_review(self, review_id: str, reviewer: str,
                          decision: str, comments: Optional[List[Any]] = None) -> dict:
        review = self._api_reviews.get().get(review_id)
        if not review:
            return {"error": f"Review not found: {review_id}"}
        if decision not in {"approve", "request_changes", "comment"}:
            return {"error": f"Invalid decision: {decision}"}
        ts = Timestamp.now(reviewer)
        updated = dict(review)
        updated["status"] = decision
        updated["comments"] = list(comments or [])
        reviewed_by = list(updated.get("reviewed_by") or [])
        if reviewer not in reviewed_by:
            reviewed_by.append(reviewer)
        updated["reviewed_by"] = reviewed_by
        updated["_updated_by"] = reviewer
        updated["_updated_at"] = ts.wall_time
        self._api_reviews.update(lambda m: m.set(review_id, updated, ts))
        endpoint_id = review.get("endpoint_id")
        self._emit(
            "api_review_submitted",
            {"review_id": review_id, "endpoint_id": endpoint_id, "reviewer": reviewer,
             "decision": decision, "comments": list(comments or [])},
            recipients=[review.get("created_by")] if review.get("created_by") else [],
            priority="high" if decision == "request_changes" else "normal",
        )
        return updated
```
