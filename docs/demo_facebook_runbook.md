## Architecture quick-recall (in case asked)

- **Stack**: React + Vite SPA / FastAPI + SQLAlchemy 2.0 async backend /
  PostgreSQL 16 / nginx serving the SPA + reverse-proxying /api/* to
  backend:8000.
- **Containers**: `fb-db` (postgres:16-alpine), `fb-db-init` (one-shot
  schema init), `fb-backend` (FastAPI on :8000), `fb-frontend` (nginx on
  :5173). All wired by `docker/docker-compose.yml`.
- **Backend self-seeding**: on first boot, the backend sees an empty
  `users` table and runs `seed.py` → creates ~50 users, posts,
  friendships, reels, listings, notifications, messages — including the
  3 test accounts above. Subsequent boots are no-ops.
- **Auth**: bcrypt + cookie-session at `app/backend/src/auth.py`.
- **Reference design**: 8 Facebook screenshots at
  `reference_images/facebook/` (login, create_account, home, people,
  reels, marketplace, post_details, settings).

## Recovery — if things break

### App container went down

```bash
cd /data/common/haibotong/env-gen/generated/facebook-web
bash scripts/start.sh
# rebuilds + waits for backend healthcheck, prints "Ready! → http://localhost:5173"
```

Takes ~3-5 min on a cold start (npm install rebuilds the frontend image).

### Live monitor unresponsive

```bash
ps -ef | grep live_monitor_server | grep -v grep
# expected: 1 python process bound to :4500

# If missing, restart:
cd /data/common/haibotong/env-gen/agent/env_generator/llm_generator
nohup /home/haibotong/miniconda3/envs/dt/bin/python live_monitor_server.py \
  --workspaces-root /tmp/envgen_demo --host 0.0.0.0 --port 4500 \
  > /tmp/monitor.log 2>&1 &
sleep 3
curl -s http://127.0.0.1:4500/api/ping
```

## Don't-touch list

- **Don't** stop `fb-db` mid-demo (loses DB state; seed is auto on empty
  DB but adds an awkward 30s pause).
- **Don't** modify `/tmp/envgen_demo/facebook-clone/project.json` during
  the demo (the live_monitor caches the project list but rereads it on
  each request, so corrupted JSON breaks the API).
- **Don't** push the `agent/tmp/demo_backup_*/` to git — it's gitignored
  by repo `.gitignore` but verify before committing anything.
